# Evidencias para informe PDF y defensa

Guardar capturas **sin credenciales, contraseñas ni URIs completas** de:
1. Cluster M0 y colecciones.
2. Ejemplos de documentos relacionados.
3. Swagger mostrando CRUD.
4. Baja lógica en MongoDB y exclusión de listados.
5. Script ejecutado y salida de `mongodump`.

El informe PDF final se elabora después de validar el prototipo; no se necesita automatizarlo.

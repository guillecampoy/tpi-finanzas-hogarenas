# Contrato API y pruebas

OpenAPI se genera desde código con springdoc. Al implementar endpoints, documentar DTOs, ejemplos de request/response, códigos HTTP y escenarios de baja lógica.

- UI local: http://localhost:8080/swagger-ui.html
- JSON: http://localhost:8080/v3/api-docs

Escenarios mínimos: crear, leer, modificar, dar de baja, no ver el movimiento en listados, intentar modificar un inactivo, ID inválido y monto inválido.

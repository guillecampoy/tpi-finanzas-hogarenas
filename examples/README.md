# Datos de demostración

Preparar un dataset sintético pequeño:
- 2 usuarios, 2 cuentas, 3 categorías, 6 movimientos.
- 1 movimiento marcado inactivo para evidenciar baja lógica.
- 1 ingreso y 5 egresos, montos decimales y fechas variadas.

No usar datos financieros reales ni datos personales del grupo. Pendiente decidir si cargarlo con `mongosh` o un script idempotente.
